# Loop Social

A social media MVP inspired by Instagram, Twitter, and Snapchat.

## Features included
- Responsive social feed layout
- Story cards and profile summary
- Post composer and post cards
- Trending and suggestions panels
- Messages panel inspired by social apps

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Tech stack
- Next.js
- TypeScript
- React

## Notes
This is the starting point for a full social platform. The next step can include authentication, real post creation, image uploads, stories, notifications, and direct messages.
